# RaceDay - Event Management System

## System Description

RaceDay is a full-stack web-based event management system designed specifically for the South African road running, walking, and cycling community. The platform aims to transition local events away from paper-based registration and disconnected communication channels. It allows organisers to efficiently manage events and results, while enabling participants to browse upcoming events, enter races, and track their personal performance history.

## System Roles

The system enforces role-based access and supports two distinct user roles:

* **Organiser:** Can create, edit, and delete events, manage event categories, view all event enrolments, and capture participant results.


* **Participant:** Can create an account, browse upcoming events, enter an event by selecting a specific category, view their personal enrolments, and track their personal race results.



## Part 1: System Planning and Database

This repository currently contains the system planning deliverables for Part 1. All planning documents are located in the folder:

* **Entity Relationship Diagram (ERD):** Visual representation of the database schema
* **API Endpoint Plan:** A structured table detailing all planned RESTful API routes 
* **SQL Database Script:** A T-SQL script to create the database schema and insert seed data.
